# 🎮 OctoArcade
## Unblocked Games Platform — Powered by CalcSolver

### Welcome to OctoArcade, a massive collection of browser‑based games built for speed, creativity, and fun.
This project started as Wii and evolved into a full‑scale arcade with thousands of games, bookmarklets, and tools.

### 🚀 Features
3K+ HTML5 games organized by category

 Bookmarklet hub with fun, hacker‑style tools

Custom icons and thumbnails for every game

 Fast loading with optimized scripts and caching

Weekly updates — new games every weekend

 Stealth & school‑friendly modes
Proxies that bypass internet cencorship
> [!TIP]
> Proxies are just unblockers

 🧩 Folder Structure
Folder	Purpose
/Games	All playable game files
/Icon	Game thumbnails and icons
/bookmarklets	Fun tools and scripts (e.g., hacker terminal, rainbow mode)
